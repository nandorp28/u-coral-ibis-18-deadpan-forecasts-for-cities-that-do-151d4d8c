Entry for the [make.fun bounty "Deadpan Forecasts for Cities That Do Not Exist"](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c).

The program writes a single deadpan weather forecast line (133 characters) for the invented city of Dampford to `/output/entry.txt`:

> Dampford: 12°C, 100% chance of rain until 6pm; residents have opened their umbrellas indoors, and the ceilings are suing for damages.

## Run

```sh
node main.ts
```
